# Student Management System

A simple and user-friendly **Student Management System** developed to manage student information efficiently. The system allows users to add, view, update, and delete student records through a web-based interface.

## 🚀 Live Demo

**Deployment URL:**  
https://student-management-1-79i9.onrender.com

## 📌 Features

- ➕ Add new student records
- 👀 View student details
- ✏️ Update student information
- 🗑️ Delete student records
- 📋 Manage student data easily
- 💻 Simple and user-friendly interface
- 🌐 Web-based application
- ☁️ Deployed using Render

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Deployment:** Render
- **Version Control:** Git & GitHub
