Project Overview & Academic Purpose

College Mini Project Prototype

The Student Management System (SMS) is a lightweight, responsive web-based academic administration platform. Developed specifically for college and university departments, it digitalizes student record keeping, class attendance monitoring, examination marks calculation, and academic standing classification.

The system employs a clean, modular Python Flask backend with an integrated SQLite database engine. All calculations—including percentage thresholds, letter grades (A+ through F), and risk indicators—are computed dynamically rather than hardcoded.

Technologies & Frameworks

  • Backend Framework: Python Flask 3.x
  • Database Engine: SQLite 3 (Embedded Native)
  • Frontend Markup: HTML5 Semantic Elements
  • Styling System: Vanilla CSS3 (Bespoke Design Tokens)
  • Client-side Scripting: Vanilla JavaScript (ES6+)
  • Data Visualizations: Chart.js 4.x via CDN

Core Modules Implemented

  • Dashboard: Real-time KPIs, enrollment distribution, active notifications.
  • Student Directory: Complete records, live search, multi-field filtering.
  • Full CRUD: Add, edit, delete, view profiles with validation.
  • Course & Dept Management: Relational foreign key bindings.
  • Attendance Tracking: Automated absent calculation and progress indicators.
  • Marks & Grading: Internal/external score summation with letter grades.
  • Academic Standing: Status classified into Excellent, Good, Needs Attention, At Risk.
  • Institutional Reports: Formatted printable dossiers with signature blocks.

Project Limitation Notice

“This project is a college-level prototype designed for educational purposes. It demonstrates student information management, attendance tracking, marks management, and basic academic analysis. It is not intended to replace official college ERP or academic management systems.”
